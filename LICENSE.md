## How to keep your copy private

Do not use GitHub's Fork button. Instead, push a clone of this repository to
an empty private repository that you own:

```bash
# 1. Create an empty private repository. This example uses the GitHub CLI;
#    you can also use the GitHub website. Do not add a README or licence.
gh repo create <your-account>/exercise-workflows --private

# 2. Clone this repository and point it at your private repository.
git clone https://github.com/uug-ai/exercise-workflows.git
cd exercise-workflows
git remote rename origin upstream
git remote add origin https://github.com/<your-account>/exercise-workflows.git
git push -u origin main

# 3. To fetch later updates to the exercise:
git pull upstream main
```

Before you push, check that no `.env` file or other credentials are staged.
This repository's `.gitignore` excludes `.env` files by default.
